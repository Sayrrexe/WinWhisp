## [Unreleased]
### Fixed
- Whisper-петли в тишине и шумных хвостах больше не пролезают в текст. Новый детектор `is_repetition_loop` отсекает результаты, где одна и та же 1–4-словная фраза повторяется подряд 4+ раза (например, «Vmware vmware vmware vmware vmware» или «iPhone X, iPhone X, iPhone X, …»). Срабатывает и в PTT-диктовке, и в файловых джобах (с фильтрацией на уровне отдельных SRT-сегментов).
- Расширен встроенный blocklist галлюцинаций: добавлены `~продолжение в следующей`, `~продолжение в следующем` и `~pydancrypt` — в логах за 2 недели такие галлюцинации Whisper встречались и попадали в инжект (особенно «Pydancrypt» как короткое наваждение в тишине, искажение хотворда `pydantic`).
- Главная причина Whisper-«хвостов» («Спасибо за просмотр», «продолжение в следующем» и т. п.) в live-диктовке — устранена в источнике, а не блок-листом. Раньше каждый чанк, отрезанный по тишине, заканчивался ~0.8 с пустого хвоста (`chunk_silence_s` целиком включался в эмит), и для Whisper это был учебниковый триггер для outro-токенов. Теперь silence-cut эмитит speech + короткий акустический pad (`audio.keep_silence_pad_ms`, по умолчанию 120 мс), а саму тишину дропает из carry-over, чтобы следующий чанк не стартовал с молчания.
- Хвостовой чанк, который улетает в ASR при отпускании горячей клавиши, теперь обрезается по тишине: если пользователь отпустил кнопку в паузу — короткое почти-молчание не доходит до Whisper и не порождает outro. Polный silence-tail дропается, короткое слово на release эмитится как есть.
- ASR-воркер на live-пути теперь сначала проверяет, не молчание ли пришло (`is_mostly_silent`), и в этом случае не дёргает Whisper вовсе. Громкость поднимается через peak-normalize (`audio.peak_normalize`, до +18 дБ с клипом по 0.95) — Whisper лучше работает с речью на нормальной громкости, как и в файловом пайплайне (там это делает ffmpeg `loudnorm`).
- Для коротких чанков (< `asr.short_audio_s`, по умолчанию 1.5 с) отключён `temperature_fallback` и поднят `no_speech_threshold` (`asr.short_audio_no_speech_threshold`, по умолчанию 0.75 против базовых 0.6). Именно высокие температуры на коротком молчании порождают уверенный outro; раньше для них модель оставалась без `initial_prompt`, без condition_on_previous_text и с полным fallback-ladder до t=1.0.

## [0.1.10] - 2026-05-11
### Added
- Транскрипция файлов теперь выдаёт SRT с настоящими таймкодами от Whisper по каждой фразе, а не одной строкой на 30-секундный чанк (`files.srt_use_segments`, по умолчанию включено). Старый режим «одна реплика на чанк» остаётся доступным через настройку.
- Тонкие настройки качества faster-whisper в `asr`: `temperature_fallback`, `no_speech_threshold`, `log_prob_threshold`, `compression_ratio_threshold`, `repetition_penalty`, `word_timestamps`, `task` (`transcribe`/`translate`), `sampling_strategy` (`beam`/`greedy`), `best_of`. Дефолты подобраны под рабочие пресеты Whisper и не меняют поведение PTT-диктовки.
- Нормализация громкости звуковой дорожки при извлечении (ffmpeg `loudnorm`, `files.loudnorm`, по умолчанию включена) — тихие записи и записи с большим LRA транскрибируются стабильнее.

### Fixed
- Авто-обновление теперь действительно перезапускает приложение после установки новой версии. Раньше расчёт был на Inno Setup флаги `/CLOSEAPPLICATIONS /RESTARTAPPLICATIONS` и `RestartApplications=yes`, но они работают только если приложение зарегистрировано в Windows Restart Manager — для tray-app это не так, поэтому WinWhisp оставался выключенным после обновления. Теперь установщик оборачивается во временный `.cmd`-скрипт (`%LOCALAPPDATA%\WinWhisp\updates\run_update.cmd`), который ждёт завершения silent-инсталлятора и сам запускает обновлённый `winwhisp.exe`; само приложение завершает процесс через 1.5 сек после старта установщика, чтобы освободить файлы для замены.

## [0.1.9] - 2026-05-03
### Changed
- Дашборд переработан под дефолтное окно 960×640: hero-карточка, статистика и блок обновления теперь умещаются целиком вместе с рядом нижних кнопок без вертикального скролла. Уменьшены размеры orb (150→116), заголовка hero (38→30px), значений статистики (34→26px), номера версии (36→24px) и спарклайнов (34→24px); подтянуты внутренние отступы карточек и общий outer-margin.
- Кнопки действий («config.yaml», «vocab.yaml», «Транскрипты», «Логи», «Проверить», «Перезагрузить») теперь центрируют группу «иконка + текст» внутри ширины и автоматически расширяются под длину подписи — текст больше не клипается и не прижимается к левому краю.
- Pill «HOLD <хоткей>» в hero-карточке расширен и центрирован стретчами с обеих сторон, длинные подписи вроде «Right Ctrl» влезают целиком и сидят по центру.
- Кнопка «Перезагрузить» теперь полностью перезапускает приложение (новый процесс через `QProcess.startDetached` с детектом `pythonw.exe`/PyInstaller), а не просто перечитывает конфиг.
- Убран служебный маркер «● live · 7 дней» в шапке карточки статистики — он не нёс смысла для пользователя.

## [0.1.7] - 2026-05-02
### Added
- На странице «Файлы» появились фильтры списка по статусу — Все · Активные · Готовые · Ошибки.

### Changed
- Все иконки в интерфейсе заменены на единый набор Lucide: пиктограммы в сайдбаре настроек, на дашборде, в очереди файлов, на странице истории, в онбординге, тостах и оверлее теперь нарисованы из SVG с антиалиасингом вместо разнокалиберных юникод-символов.
- Страница «Файлы» переделана в минималистичный list view: drop-зона уехала в компактную горизонтальную полосу сверху, очередь больше не оформлена карточками, кнопки действий появляются при наведении на элемент, детали ошибок ffmpeg раскрываются прямо под именем файла.
- Палитра приложения стала светлее: фон окна и контента переехал с почти-чёрного `#0A0A0B` на `#1B1B1F`, сайдбар — на `#16161A`, карточки теперь читаются как тёмные углубления в светлом фоне. Границы и ховер-эффекты унифицированы под новый тон.
- Кнопки в футере онбординга («Назад» / «Далее») теперь оформлены как primary-кнопка и link-кнопка из основного UI: «Далее» заметна зелёной заливкой. Со страницы выбора хоткея убран длинный поясняющий подзаголовок, со страницы «Готов к диктовке» — зелёный пульсирующий кружок над заголовком.

### Fixed
- Иконки во всём интерфейсе (онбординг, настройки, оверлей) больше не выглядят размытыми на HiDPI-мониторах — пиксмапы SVG-иконок рисуются с учётом device pixel ratio.
- Карточки выбора модели и хоткея, бэйджи «ПО УМОЛЧАНИЮ»/«РЕКОМЕНДОВАНО», иконные плашки и кнопка «Захватить» в онбординге больше не имеют пиксельно-зазубренных границ — углы рисуются с антиалиасингом.
- Радиокружок в карточке «Свой вариант» на шаге выбора хоткея больше не съезжает относительно заголовка — размер выровнен с остальными карточками.
- Подзаголовок на шаге «Готов к диктовке» больше не обрезается при переносе строки.

## [0.1.6] - 2026-05-02
### Fixed
- Иконка в трее больше не остаётся «призраком» после выхода из приложения — теперь скрывается явно перед завершением процесса.
- Автозапуск с Windows больше не открывает приложение в окне терминала — используется `pythonw.exe` вместо `python.exe`.
- Чекбокс автозапуска в настройках теперь всегда отражает реальное состояние реестра: синхронизация происходит до построения UI, а не после.
- Диалог записи горячей клавиши снова различает `left ctrl`/`right ctrl`, `left alt`/`right alt`, `left shift`/`right shift` и `left/right windows` — раньше Qt-события склеивали стороны, и записать хоткей именно на правый модификатор было невозможно. Заодно глобальный клавиатурный хук теперь освобождается сразу после сохранения, а не оставался зарегистрированным до уничтожения диалога.
- Закруглённые углы кнопок в настройках, а также бейджей, иконок статуса и drop-зоны на странице «Файлы», больше не выглядят пиксельно-зазубренными — границы рисуются с антиалиасингом.

## [0.1.5] - 2026-05-01
### Added
- Кнопка «изменить» рядом с горячей клавишей теперь открывает диалог записи комбинации: нажатая клавиша сразу попадает в `cfg.hotkey.combo`, отдельно различаются `right ctrl`/`left ctrl`, `right alt`/`left alt`, `right shift`/`left shift`, `right windows`/`left windows`. Применяется после перезапуска приложения.

### Fixed
- Приложение больше не зависает в состоянии «Обработка», если выбрана нескачанная модель или модель не удалось загрузить — нажатие хоткея с отсутствующей моделью теперь сразу показывает уведомление и не запускает запись.
- При системном масштабе Windows ≠ 100 % правая и нижняя половина окна настроек больше не «глушат» клики — dropdown'ы и кнопка «Установить» снова реагируют с первого клика. Раньше из-за рассогласования physical/logical координат в hit-тесте frameless-окна эти зоны воспринимались как resize-handle.

## [0.1.4] - 2026-04-27
### Added
- New "Files" section in the settings window: drag audio or video into the window (or open it via tray → "Files…") and the audio track is extracted with ffmpeg and saved as `.txt` and `.srt` in `Documents\WinWhisp\transcripts\`. Supports mp3, mp4, wav, m4a, mkv, ogg, opus, and other common formats.
- Hotkey transcription takes priority over file transcription: pressing the hotkey pauses file processing at the current segment, and recognition resumes automatically once the hotkey is released.
- New "Files…" tray menu item with an active-jobs counter opens the window directly on the "Files" page.
- New `files` section in `config.yaml` to configure chunk length, silence threshold, output directory, and output formats.

### Changed
- ffmpeg is now bundled with the installer build, so file transcription works out of the box without requiring ffmpeg in PATH.

## [0.1.3] - 2026-04-27
### Added
- Новые поля конфига: `asr.short_audio_s` (порог короткого аудио для отключения промпта, по умолчанию 1.5 с) и `vocab.prompt_prefix` (преамбула `initial_prompt`-а Whisper). Можно править в `%APPDATA%\WinWhisp\config.yaml` без пересборки.

### Fixed
- Артефакты вида «Используются термины по программированию», которые Whisper иногда вставлял из internal-промпта, теперь отсеиваются и не попадают в текст.
- Короткие хвостовые фрагменты речи (≤1.5 с) больше не «склеиваются» с эхом промпта — для них модель работает без `initial_prompt`, что повышает шанс распознать остаток фразы вместо потери.
