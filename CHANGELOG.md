# Changelog

Все значимые изменения проекта документируются здесь.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
проект следует [Semantic Versioning](https://semver.org/lang/ru/).

## [Unreleased]
### Added
- Новые поля конфига: `asr.short_audio_s` (порог короткого аудио для отключения промпта, по умолчанию 1.5 с) и `vocab.prompt_prefix` (преамбула `initial_prompt`-а Whisper). Можно править в `%APPDATA%\WinWhisp\config.yaml` без пересборки.

### Fixed
- Артефакты вида «Используются термины по программированию», которые Whisper иногда вставлял из internal-промпта, теперь отсеиваются и не попадают в текст.
- Короткие хвостовые фрагменты речи (≤1.5 с) больше не «склеиваются» с эхом промпта — для них модель работает без `initial_prompt`, что повышает шанс распознать остаток фразы вместо потери.

## [0.1.2] - 2026-04-26
### Added
- README с баннером и иконка приложения обновлены до фирменного стиля WinWhisp.
- Документ `BUILDING.md` с инструкцией по сборке из исходников и репродюсибельному инсталлятору.

### Fixed
- Окно онбординга при первом запуске больше не появляется без фокуса — кнопки реагируют на клик сразу.
- Скачивание модели через SOCKS-прокси: добавлен `socksio`, ошибка «Using SOCKS proxy, but the 'socksio' package is not installed» больше не возникает.

## [0.1.1] - 2026-04-26
### Added
- Вкладка «Логи и диагностика» в настройках: живая лента событий с подсветкой уровней, фильтр по уровню, ссылки на лог-файл, конфиг и папку моделей.

## [0.1.0] - 2026-04-26
### Added
- Первая публичная сборка WinWhisp: PTT-диктовка с трей-иконкой, faster-whisper на CUDA с автофоллбэком на CPU/int8.
- CI-пайплайн: PyInstaller-бандл, Inno Setup installer и portable-zip собираются в GitHub Actions при push тега `v*`.
